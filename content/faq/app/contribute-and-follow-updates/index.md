You can [donate](@/donate/index.md), improve OpenStreetMap, translate the app or website, test beta versions, help other users, report reproducible problems, or contribute code and design. Store reviews and recommendations to friends also help people discover Organic Maps.

Start with the [contribution page](@/contribute/index.md) for current tools and community links. For code, use the [project repository](https://github.com/organicmaps/organicmaps) and its development instructions. For a UI proposal, show the user problem and an example of the proposed behavior.

## Where can I follow updates, join testing, or suggest a feature? {#roadmap-and-news}

Read [release news](/news/) for shipped features and beta invitations. Use the current testing links there to join the appropriate platform's beta program. Beta features can change and may not yet be in the store release.

Search existing [issues](https://github.com/organicmaps/organicmaps/issues) and [ideas](https://github.com/orgs/organicmaps/discussions/categories/ideas) before proposing a feature. Describe the task you want to complete and why current behavior does not meet it. Release dates depend on development and testing; an open proposal is not a delivery promise.
