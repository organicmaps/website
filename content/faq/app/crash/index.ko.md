Android에서 지도를 SD 카드에 저장한다면 SD 카드에 문제가 있을 가능성이 큽니다. 다음 방법을 시도해 보세요.
1. 다운로드한 지도를 모두 삭제한 다음 SD 카드에 다시 다운로드하세요(같은 문제가 발생할 수 있습니다).
2. 다운로드한 지도를 모두 삭제하고 내부 저장소를 선택한 다음 지도를 다시 다운로드하세요.
3. SD 카드를 포맷한 다음 지도를 다시 다운로드하세요.
4. 새 SD 카드를 사용하세요(권장).

앱이 계속 비정상 종료되면 [GitHub](https://github.com/organicmaps/organicmaps/issues/)에 비슷한 문제가 있는지 확인한 후 다음 정보를 담아 [문의해 주세요](mailto:support@organicmaps.app).

* 문제에 대한 자세한 설명과 문제를 재현하는 단계
* Organic Maps 버전
* 기기 모델과 운영체제 버전(Android 또는 iOS)

오류 신고는 다음 방법으로도 할 수 있습니다.
1. 앱 설정에서 ‘로깅 사용’을 켜세요.
2. 앱을 강제로 종료한 후 다시 실행하세요.
3. 앱이 비정상 종료되는 상황을 재현하세요.
4. 앱 정보 화면의 ‘오류 신고’에서 로그 파일을 보내고 문제가 발생한 상황을 간단히 설명해 주세요.
