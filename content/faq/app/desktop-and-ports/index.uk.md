Доступні версії для настільних комп’ютерів під Linux та macOS. Версія для Windows перебуває на стадії розробки. Інтерфейс та набір функцій відрізняються від мобільних застосунків. Див. [інструкцію щодо Flatpak для Linux](@/faq/linux/how-to-use-flatpak/index.uk.md) і [сторінку завантаження релізів проєкту](https://github.com/organicmaps/organicmaps/releases).

Також триває розробка версій для GTK, Qt Quick, Sailfish та Flutter. Ці роботи дозволять запропонувати Organic Maps для інших платформ та з іншими інтерфейсами; їхня доступність та набір функцій можуть відрізнятися.
