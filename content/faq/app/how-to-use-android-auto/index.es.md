Para usar Android Auto por cable, necesitas Android 11 o una versión posterior. Instala Organic Maps desde Google Play. Android Auto solo muestra las aplicaciones de navegación instaladas desde una fuente de confianza.

Por favor, consulta la [página web de Android Auto](https://support.google.com/androidauto/answer/6348019) para obtener más detalles.
