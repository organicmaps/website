Pour utiliser Android Auto avec un câble, il te faut Android 11 ou une version ultérieure. Installe Organic Maps depuis Google Play. Android Auto affiche uniquement les applications de navigation installées depuis une source fiable.

Merci de consulter le [site web d'Android Auto](https://support.google.com/androidauto/answer/6348019) pour plus de détails.
