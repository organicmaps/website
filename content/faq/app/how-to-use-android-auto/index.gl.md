Para usar Android Auto por cable, precisas Android 11 ou unha versión posterior. Instala Organic Maps desde Google Play. Android Auto só amosa as aplicacións de navegación instaladas desde unha fonte de confianza.

Consulta o [sitio web de Android Auto](https://support.google.com/androidauto/answer/6348019) para obter máis detalles.
