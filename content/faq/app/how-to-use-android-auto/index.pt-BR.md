Para usar o Android Auto por cabo, você precisa do Android 11 ou de uma versão posterior. Instale o Organic Maps pelo Google Play. O Android Auto só exibe aplicativos de navegação instalados de uma fonte confiável.

Consulte o [site do Android Auto](https://support.google.com/androidauto/answer/6348019) para obter mais detalhes.
