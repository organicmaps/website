Да. Внешний API позволяет другому приложению открывать Organic Maps для отображения одного или нескольких мест, выполнения поиска или прокладки маршрута. Например, приложение для путешественников может отображать на карте рекомендуемые им остановки, а приложение для Android может запросить у пользователя выбор точки и получить её координаты в ответ.

Попробуйте [интерактивные примеры API и глубоких ссылок на omaps.app/api](https://omaps.app/api). Код для интеграции и примеры приложений доступны в [репозитории organicmaps/api-ios](https://github.com/organicmaps/api-ios) для Swift и Objective-C, а также в [репозитории organicmaps/api-android](https://github.com/organicmaps/api-android) для Java и Kotlin. Эти API запускают установленное приложение Organic Maps; воспользуйтесь [SDK](@/faq/developers/sdk/index.ru.md) для встраивания карт в ваш собственный интерфейс.
