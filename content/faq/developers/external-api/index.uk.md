Так. Зовнішній API дозволяє іншому застосунку відкривати Organic Maps для відображення одного або кількох місць, виконання пошуку або прокладання маршруту. Наприклад, застосунок для подорожей може відображати на мапі рекомендовані ним зупинки, а застосунок для Android може запросити в користувача вибір точки й отримати її координати у відповідь.

Спробуйте [інтерактивні приклади API та глибоких посилань на omaps.app/api](https://omaps.app/api). Код для інтеграції та зразки застосунків доступні в [репозиторії organicmaps/api-ios](https://github.com/organicmaps/api-ios) для Swift та Objective-C, а також [в organicmaps/api-android](https://github.com/organicmaps/api-android) для Java та Kotlin. Ці API відкривають встановлений застосунок Organic Maps; скористайтеся [SDK](@/faq/developers/sdk/index.uk.md), щоб вбудувати мапи у власний інтерфейс.
