Да. С помощью Android SDK вы можете интегрировать в приложение для Android функции отображения карт Organic Maps, офлайн-поиска, загрузки карт, добавления меток и прокладки маршрутов. В [примерах из репозитория organicmaps/sdk-android](https://github.com/organicmaps/sdk-android) продемонстрированы: базовая карта, загрузка карт для работы без интернета и поиск, а также прокладка маршрутов и навигация.

Для настройки и получения подробной информации об API следуйте [руководству по интеграции Android SDK](https://github.com/organicmaps/organicmaps/blob/master/android/sdk/README.md). SDK постоянно развивается, поэтому при интеграции необходимо отслеживать изменения в его API. Планируется выпуск SDK для iOS; приложения для iOS уже могут использовать [внешний API](@/faq/developers/external-api/index.ru.md) для запуска Organic Maps и обмена информацией.

## Можно ли повторно использовать исходный код Organic Maps? {#license}

Исходный код самого проекта распространяется в соответствии с лицензией Apache 2.0. Ознакомьтесь с [лицензией](https://github.com/organicmaps/organicmaps/blob/master/LICENSE) репозитория и уведомлениями, касающимися включённых компонентов. Лицензия на исходный код регулируется отдельно от лицензий на картографические данные и другие ресурсы.
