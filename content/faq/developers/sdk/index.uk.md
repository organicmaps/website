Так. SDK для Android дозволяє інтегрувати в застосунок для Android функції відображення мап Organic Maps, офлайн-пошук, завантаження мап, мітки та прокладання маршрутів. У [прикладах з репозиторію organicmaps/sdk-android](https://github.com/organicmaps/sdk-android) продемонстровано базову мапу, завантаження офлайн-мап та пошук, а також планування маршрутів і навігацію.

Для налаштування та отримання детальної інформації про API дотримуйтесь [інструкції з інтеграції Android SDK](https://github.com/organicmaps/organicmaps/blob/master/android/sdk/README.md). SDK постійно вдосконалюється, тому при інтеграції слід відстежувати зміни в його API. Планується випуск SDK для iOS; застосунки для iOS вже можуть використовувати [зовнішній API](@/faq/developers/external-api/index.uk.md) для запуску Organic Maps та обміну інформацією.

## Чи можна повторно використовувати вихідний код Organic Maps? {#license}

Власний вихідний код проєкту розповсюджується на умовах ліцензії Apache 2.0. Ознайомтеся з [ліцензією](https://github.com/organicmaps/organicmaps/blob/master/LICENSE) репозиторію та повідомленнями щодо включених компонентів. Ліцензія на вихідний код регулюється окремо від ліцензій на дані мап та інші матеріали.
