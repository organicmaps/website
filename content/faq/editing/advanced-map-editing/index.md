Use an OpenStreetMap editor for geometry changes and features the Organic Maps editor does not support, including roads, paths, building outlines and moving places. On a computer, use the browser-based [ID Editor](https://www.openstreetmap.org/edit):

1. Create an account or sign in at [OpenStreetMap.org](https://www.openstreetmap.org/).
2. Go to the location you want to change and click **Edit**.
3. Follow the ID Editor walkthrough if you are new to editing.
4. Make your changes and save them with a clear description.

For editing on a phone, the existing options include [Go Map](https://apps.apple.com/us/app/go-map/id592990211) on iOS and [Vespucci](https://play.google.com/store/apps/details?id=de.blau.android) on Android. LearnOSM has tutorials for [Go Map](https://learnosm.org/en/mobile-mapping/gomap/) and [Vespucci](https://learnosm.org/en/mobile-mapping/vespucci/). For simpler contributions, you can also use [Every Door](https://every-door.app/) or [StreetComplete](https://streetcomplete.app/).

## How do OpenStreetMap tags work?

OpenStreetMap describes features with tags such as their type, access, surface, and opening hours. A tag is a key-value pair: a restaurant can have `amenity=restaurant`, with `cuisine=*` and `opening_hours=*` providing more detail. The editor provides forms for common tags; in ID Editor, expand **Tags** in the feature's sidebar to inspect them.

Consult the [OpenStreetMap Wiki](https://wiki.openstreetmap.org/) for unfamiliar mapping conventions or ask in the [OpenStreetMap community forum](https://community.openstreetmap.org/c/help-and-support).

## Who reviews map edits, and what happens if somebody else changes the same place? {#osm-review}

OpenStreetMap contributions are public and can be reviewed and corrected by other contributors; they are not all approved in advance. Organic Maps attempts to merge supported edits with the current OpenStreetMap object when uploading. Conflicts or deleted objects can prevent an upload, so check the edit status if a change has not appeared.

Check messages on your OpenStreetMap account if other contributors ask about your changes. Your username and contributions are public. A successful upload will still need a later Organic Maps data snapshot before it reaches other users through a map update; see [map updates and the map-data date](@/faq/map/update-offline-maps/index.md#map-data-date).

## How do I add an OpenStreetMap note? {#osm-note}

If you cannot edit the map yourself, add a note that another contributor can investigate:

1. Open [OpenStreetMap.org](https://www.openstreetmap.org/) and zoom to the exact location. Sign in if you want to follow replies.
2. Choose **Add a note to the map** and position the marker accurately.
3. Describe what is wrong, what should be there and how you know, then choose **Add Note**. For a business, include its name and the services it offers.

Notes are public and may take time for a volunteer to resolve. Do not include private contact details. A note reports a problem; it does not immediately change the map or create a personal bookmark. You can also use the [reporting option in Organic Maps](@/faq/editing/map-errors/index.md).
