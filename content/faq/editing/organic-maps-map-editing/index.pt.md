Com o Organic Maps, podes facilmente adicionar lugares ausentes ao mapa, adicionar detalhes adicionais, como horário de funcionamento, ou corrigir entradas erradas. Ao fazer isso, melhoras os dados do mapa para todos os usuários.

Como [OpenStreetMap(OSM)](https://wiki.openstreetmap.org/wiki/About_OpenStreetMap) é a principal fonte de dados de mapas no Organic Maps, as edições que fazes são enviadas ao OSM. OSM é um projeto comunitário para construir um mapa gratuito e aberto. Funciona de forma semelhante à Wikipedia, então tudo que editas fica disponível para milhões de usuários em todo o mundo. Junta-te à comunidade e ajuda a fazer um mapa melhor para todos!

**Para editar o OpenStreetMap a partir do teu aplicativo Organic Maps:**
1. Cria uma conta em [OpenStreetMap.org](https://www.openstreetmap.org/user/new)
2. Faz login na tua conta no Organic Maps (ícone de hambúrguer -> *configurações* -> *OpenStreetMap-Profile*)
3. Agora podes editar locais existentes ou adicionar novos
	- Editar local existente
		- seleciona o local tocando no ícone do mapa
		- toca em *editar local*
		- Adiciona informações adicionais
		- Salva as tuas alterações e sai usando a seta de verificação
	- Adiciona um lugar ao mapa
		- ícone de hambúrguer -> *Adicionar um lugar ao OpenStreetMap*
		- Seleciona o local com a maior precisão possível e pressiona a seta de verificação
		- Seleciona uma categoria
			> Não consegues encontrar uma categoria adequada? Em seguida, cria uma [Nota OSM](@/faq/editing/advanced-map-editing/index.pt.md#osm-note).
		- Adiciona informações adicionais como nome, horário de funcionamento e site
		- Salva as tuas alterações e sai usando a seta de verificação

Nota que o editor foi concebido como um simples editor de POI e, portanto, limitado a POIs. Não podes, por exemplo, adicionar estradas, lagos, contornos de edifícios, etc. Além disso, não é possível mover locais para um novo local. Se não consegues editar algo com o Organic Maps, dá uma olhada na página [Edição mais avançada de mapas](@/faq/editing/advanced-map-editing/index.pt.md).
