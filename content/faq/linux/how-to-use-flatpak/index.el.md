Για να εγκαταστήσεις το OM σε Linux με flatpak, άνοιξε το τερματικό και πληκτρολόγησε «flatpak install flathub app.organicmaps.desktop»

Μόλις εγκατασταθεί η εφαρμογή, μπορείς να χρησιμοποιήσεις τον τροχό κύλισης του ποντικιού σου ή τα χειριστήρια στη δεξιά γραμμή μενού για να κάνεις μεγέθυνση στην περιοχή που θέλεις να πλοηγηθείς για να κατεβάσεις χάρτες για αυτήν την περιοχή. Μπορείς επίσης να κάνεις κλικ στο εικονίδιο «λήψη» κάτω δεξιά. Αφού κατεβάσεις χάρτες για τις περιοχές που σε ενδιαφέρουν, η εφαρμογή θα πρέπει να λειτουργεί ακόμα και χωρίς σύνδεση στο διαδίκτυο. 

Μπορείς να τοποθετήσεις το ποντίκι σου πάνω από τα διάφορα εικονίδια για να δεις κάποιο κείμενο βοήθειας. 

Για να εκτελέσεις δρομολόγηση και περιήγηση με στροφή, έχεις μερικές επιλογές. εάν γνωρίζεις τις συντεταγμένες GPS των σημείων αφετηρίας και λήξης, μπορείς να κάνεις κλικ στο εικονίδιο ρυθμίσεων (πάνω από το πράσινο σημάδι επιλογής) και να εισαγάγεις τις συντεταγμένες του σημείου εκκίνησης και του προορισμού σου. Για να ορίσεις το σημείο εκκίνησης στον χάρτη, κάνε κλικ στο εικονίδιο πλοήγησης και επίλεξε «σημείο έναρξης», στη συνέχεια κράτησε πατημένο το πλήκτρο shift και κάνε αριστερό κλικ στον χάρτη. Για να ορίσεις τον προορισμό, άλλαξε σε «τελικό σημείο» και κάνε κλικ σε μια τοποθεσία στο χάρτη.

![Ρύθμιση σημείου έναρξης και σημείου λήξης](nav_points.png)

Μπορείς να κάνεις κλικ στο μπλε εικονίδιο ακριβώς πάνω από το εικονίδιο ρυθμίσεων για να διαγράψεις την πλοήγηση. 

![εκκαθάριση πλοήγησης](clear_route.png)

Για να αναζητήσεις διευθύνσεις και προορισμούς, κάνε κλικ στον μεγεθυντικό φακό και εισάγαγε τη διεύθυνση ή τον όρο αναζήτησης.

Για να προσθέσεις σελιδοδείκτη σε μια τοποθεσία, κράτησε πατημένο το πλήκτρο Alt και κάνε δεξί κλικ στο μέρος που θέλεις να προσθέσεις σελιδοδείκτη. Ο σελιδοδείκτης ενδέχεται να μην είναι άμεσα ορατός, για να προβάλεις και να διαχειριστείς τους σελιδοδείκτες πρέπει να κάνεις κλικ στο εικονίδιο με το κόκκινο αστέρι. 

![προβολή σελιδοδεικτών](view_bookmarks.png)

Η εφαρμογή για επιτραπέζιους υπολογιστές Linux χρησιμοποιείται κυρίως για σκοπούς ανάπτυξης (αυτόματη δοκιμή και έλεγχος λογικής χωρίς να χρειάζεται μεταγλώττιση για κινητά). Οποιοσδήποτε εθελοντής να βελτιώσει τη χρηστικότητα της έκδοσης Linux είναι ευπρόσδεκτος!
