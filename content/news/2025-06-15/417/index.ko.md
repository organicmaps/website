기여자 여러분 ❤️ 덕분에 6월 업데이트에서 여러 기능을 개선하고 오류를 수정했습니다. 계획한 경로를 저장하고, iOS에서 트랙 기록 통계를 보고, Android에서 선택한 장소의 방위각을 확인할 수 있습니다. 더 많은 기능 개선과 오류 수정이 예정되어 있습니다!

업데이트는 [App Store][appstore], [Obtainium][obtainium], [Accrescent](https://accrescent.app/app/app.organicmaps)에서 지금 받을 수 있으며 [Google Play][googleplay], [Huawei AppGallery][appgallery], [F-Droid][fdroid]에서도 며칠 안에 이용할 수 있습니다.

- 2025년 6월 8일 기준 최신 OpenStreetMap 데이터
- 계획한 경로를 트랙으로 저장 -- [@cyber-toad](https://github.com/cyber-toad), [@kirylkaveryn](https://github.com/kirylkaveryn)
- 자동차 충전소 아이콘이 덜 거슬리도록 개선 -- [@euf](https://github.com/euf)
- 묘목장, 충돌 방지 시설 및 교통 차단 시설, 라디오·TV·음악 스튜디오, 모닥불 시설, 사다리, 크레인, 러브호텔 표시 -- [@hemanggs](https://github.com/hemanggs), [@vng](https://github.com/vng)
- 칭다오 지하철 아이콘 추가 -- [@sddzhyc](https://github.com/sddzhyc), [@vng](https://github.com/vng)
- 재봉과 재단사 검색 동의어 업데이트 -- [@vng](https://github.com/vng)
- 리투아니아어 등에서 카테고리 검색 오류 수정 -- [@vng](https://github.com/vng)
- [Weblate 커뮤니티](https://hosted.weblate.org/projects/organicmaps/)에서 앱 번역 업데이트

Android:
- 장소 정보에서 거리가 표시된 작은 화살표를 누르면 북쪽 기준 방위각 표시 -- [@hemanggs](https://github.com/hemanggs)
- ‘출발지’를 누르면 길게 눌러 켠 전체 화면 모드 해제 -- [@tomadavid](https://github.com/tomadavid)
- 위치 정보가 없으면 6시와 18시에 ‘길 안내 자동’ 테마를 라이트 또는 다크 모드로 전환 -- [@hb0nd](https://github.com/hb0nd), [@vng](https://github.com/vng)
- 화면 회전 시 북마크 이름이 갱신되지 않던 문제 수정 -- [@savsch](https://github.com/savsch)
- 시스템의 TTS 음성 엔진 설정 변경을 감지해 다시 불러옴 -- [@hemanggs](https://github.com/hemanggs)
- Android 5 및 6에서 지도 위의 일부 지형지물을 선택할 때 비정상 종료되던 문제 수정 -- [@batterydotac](https://github.com/batterydotac), [@biodranik](https://github.com/biodranik)
- 드라이브스루 표시 수정 -- [@batterydotac](https://github.com/batterydotac)
- 3D 건물과 3D 원근 설정이 의도치 않게 함께 바뀌던 문제 수정 -- [@vrajs](https://github.com/vrajs)
- 다운로드 취소 버튼이 작동하지 않던 문제 수정 -- [@kavikhalique](https://github.com/kavikhalique)
- 경로 관리 버튼에서 경유 순서를 바꾸는 동작 개선 -- [@gpesquero](https://github.com/gpesquero)
- 라이트 모드에서 하단 탐색 막대를 투명하게 표시 -- [@coderang-gk](https://github.com/coderang-gk)
- 눈 아이콘을 눌러 북마크와 트랙 목록을 표시하거나 숨기는 동작 개선 -- [@kavikhalique](https://github.com/kavikhalique)
- Android 5 및 6에서 흰색 배경 위에 흰색 글자가 나타나던 문제 수정 -- [@hemanggs](https://github.com/hemanggs)
- 길 안내 중 현재 위치 화살표가 튀던 문제 수정 -- [@kavikhalique](https://github.com/kavikhalique)
- 체크 아이콘을 ‘완료’ 또는 ‘저장’ 문구로 바꾸고 누를 수 있는 영역 확대 -- [@kavikhalique](https://github.com/kavikhalique)
- 시스템 언어를 바꿔도 Google Play에서 앱을 다시 설치할 필요가 없음 -- [@vng](https://github.com/vng)

[@kirylkaveryn](https://github.com/kirylkaveryn)이 iOS의 여러 오류를 수정하고 화면을 개선했습니다.
- 기록 중인 트랙의 상세 정보 표시
- 지도와 목록에서의 검색 오류 수정
- 현재 위치를 알 수 없을 때의 경로 계획 오류 수정
- 검색 기록이 중복되지 않도록 수정
- 클라우드에 파일이 없어도 iCloud 동기화가 실패하지 않도록 수정
- 검색 추천 수정
- 내 OSM 편집 내용을 표시하는 ‘?edits’ 검색 명령에서 개수 표시 수정
- 장소 정보에서 위키백과 섹션 표시 수정
- 트랙 정보 화면을 열면 끝까지 펼쳐서 표시
- 검색 화면 위쪽에 안전 영역을 기준으로 여백 추가
- 팝업 화면 애니메이션을 더 부드럽게 개선
- 측면 버튼 애니메이션 개선
