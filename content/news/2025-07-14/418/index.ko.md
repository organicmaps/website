기여자 여러분 덕분에 여러 오류를 수정하고 기능을 개선한 Organic Maps 7월 업데이트를 선보입니다 ❤️💪! [App Store][appstore], [Obtainium][obtainium], [Accrescent][accrescent]에서 지금 받을 수 있으며 [Google Play][googleplay], [Huawei AppGallery][appgallery], [F-Droid][fdroid]에서도 며칠 안에 이용할 수 있습니다.

[후원](@/donate/index.ko.md), [지원](@/contribute/index.ko.md), [오류 신고][github issues], [개선 사항][github]을 보내 주시는 덕분에 함께 더 좋은 지도를 만들 수 있습니다!

[iOS][testflight]와 [Android][firebase]의 베타 테스트에 참여하면 실험 기능과 추가될 기능을 먼저 사용해 볼 수 있습니다.

전체 변경 내역
- 7월 8일 기준 OSM 지도 데이터, 7월 1일 기준 위키백과 지도 데이터
- 아랍어 검색 개선 (_Omar Mostafa_)
- 캠핑장과 리조트 영역을 표시하고 산업 구역이 더 낮은 확대 수준에서도 보이도록 변경 (_Viktor Govako_)
- 회전교차로에서 보조 도로도 경로 탐색에 반영 (_Viktor Govako_)
- 선택한 트랙의 확대 동작 개선 (_Kiryl Kaveryn_)
- 기록하거나 가져온 트랙을 찾기 쉽도록 지도에 새 ‘북마크 및 트랙’ 아이콘 적용 (_@euf_)
- 지도와 검색에서 충전소를 다른 장소와 구분할 수 있는 전용 아이콘 적용 (_David Martinez_)
- 경로를 저장할 때 고도 데이터가 _있는 경우_ 함께 저장 (_Kiryl Kaveryn_)
- 번역 업데이트. 잘못되거나 빠진 번역은 [Weblate][weblate]에서 수정하는 데 도움을 주실 수 있습니다.

Android:
- Android 16에서 뒤로 버튼이 작동하지 않던 문제 수정 (_Andrei Shkrob_)
- 기본적으로 라이트 테마를 사용하고 길 안내 중에는 다크 테마 적용 (_Viktor Govako_)
- OSM 편집 내용이 중복되던 문제 수정 (_Alexander Borsuk_)
- 모든 검색 결과가 지도에 표시되도록 수정 (_Viktor Govako_)
- 일부 기기의 화면 배치 오류 수정 (_Sergiy Kozyr_)
- 브라우저 로그인이 실패하거나 불가능하면 OSM 아이디와 비밀번호 입력란 표시 (_Sergiy Kozyr_)
- OpenStreetMap에 지형지물을 추가할 때 십자 표시가 튀던 문제 수정 (_@hemanggs_)
- ‘실패한 다운로드 다시 시도’ 버튼 수정 (_Kavi Khalique_)
- 앱 시작 화면이 시스템 버튼을 가리던 문제 수정 (_Vraj Shah_)
- 일부 비정상 종료 문제 수정 (_Devarsh Vasani_)
- Android 5에서 KML 또는 GPX를 가져올 때 발생하던 EACCESS PermissionDenied 오류 수정 (_Alexander Borsuk_)

iOS 변경 사항은 모두 _Kiryl Kaveryn_이 작업했습니다.
- 북마크와 트랙 편집 개선. 트랙 정보 화면에서 색상과 목록을 바로 바꿀 수 있음
- 트랙 기록을 저장한 직후 편집하거나 삭제할 수 있음
- 버튼을 누를 수 있는 영역 확대
- 텍스트를 입력할 때 OSM 메모가 갑자기 움직이던 문제 수정
- 업체에 ‘장소 추가’ 버튼 표시

자세한 업데이트 내역이 도움이 된다면 [소셜 미디어](/ko/#community)에서 알려 주세요.
