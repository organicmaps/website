## 업데이트 내역

- *신규:* 세계 지도에서 다운로드한 지역을 강조 표시 (Viktor Govako)
- *신규:* 확대 수준 8부터 세계 지도에서 자연보호구역, 국립공원, 보호 구역, 원주민 지역, 위험 지역, 호수를 표시하고 검색할 수 있음 (Viktor Govako)
- *신규:* 경로를 만들 때 도로 통제 시간을 반영 (Viktor Govako)

### 모든 플랫폼

- 2025년 11월 9일 기준 OpenStreetMap 데이터 (Viktor Govako)
- 주소를 편집하거나 OpenStreetMap에 변경 사항을 올릴 때 기본 도로명과 번역된 도로명에 생기던 문제 수정 (Viktor Govako)
- 세계 지도에서 검색 결과를 눌렀을 때 적용되는 확대 수준 수정 (Viktor Govako)
- 길 안내 중 자동 확대 설정이 작동하지 않던 경우를 수정 (Viktor Govako)

### iOS

- ‘더 보기’ 버튼으로 북마크 또는 트랙 목록을 삭제하면 이전 화면으로 제대로 돌아가도록 수정 (Kiryl Kaveryn)
- 앱 정보 화면에 [TikTok][tiktok], [Threads][threads], [Bluesky][bluesky] 링크 추가 (Kiryl Kaveryn)
- 홈 화면의 앱 아이콘 빠른 동작에 ‘오류 신고’ 추가 (Kiryl Kaveryn)
- 앱과 CarPlay에서 발생하던 여러 비정상 종료 문제 수정 (Kiryl Kaveryn)

### Android

- 텍스트 음성 변환(TTS) 설정 업데이트 (Andrei Shkrob)
- Android Auto 비정상 종료 문제 수정 (Andrei Shkrob)
- Android Auto에서 항상 자동차 경로 탐색 모드 사용 (Andrei Shkrob)
- 홍콩(zh-HK)과 마카오(zh-MO)에서 중국어 번체 번역 사용 (Alexander Borsuk)

Chromebook을 포함해 OpenGL ES 3을 지원하는 x86 기기에서 Organic Maps를 실행할 수 있다면 알려 주세요.

### 지도와 스타일

- 폐선된 철도와 사용하지 않는 철도의 표시 방식을 서로 바꿈 (Lukas Hamm)
- 지도에 시계 수리점과 학생 숙소 추가 (David Martinez)
- 여행사 아이콘 추가 (David Martinez)
- 화장실 아이콘을 회색으로 변경 (David Martinez)
- 청각 전문가, 발 전문의, 검안 시설, 보청기 아이콘 업데이트 (David Martinez)
- 다크 모드의 자전거 대여 아이콘 수정 (David Martinez)
- 세계 지도에서 미국의 주와 캐나다의 주 이름을 확대 수준 5부터 표시 (Viktor Govako)

### 번역

- 슬로베니아어 검색 동의어를 추가하고 슬로베니아어 카테고리 검색 활성화 (Alexander Borsuk)
- 아랍어, 불가리아어, 덴마크어, 독일어, 그리스어, 스페인어, 페르시아어(파르시어), 핀란드어, 헝가리어, 인도네시아어, 일본어, 한국어, 리투아니아어, 라트비아어, 노르웨이어 보크몰, 네덜란드어, 루마니아어, 슬로베니아어의 오타, 잘못된 번역, 검색 동의어를 수정하고 누락된 번역 추가 (Alexander Borsuk)
- 기본 스페인어(es)와 포르투갈어(pt)에 더해 멕시코 스페인어(es-MX) 및 브라질 포르투갈어(pt-BR) 전용 번역 추가 (Alexander Borsuk)
- 체코어 TTS 음성 안내 수정 (jxsv)
- 에스토니아어(et), 갈리시아어(gl), 히브리어(he), 리투아니아어(lt) TTS 음성 안내 활성화 (Sergiy Kozyr)
- 번역 업데이트 (Sergiy Kozyr, Weblate 기여자)

### 데스크톱

- 자연보호구역이나 호수 등 세계 지도의 지형지물을 데스크톱의 상황에 맞는 메뉴에 표시 (Viktor Govako)
- 지도 다운로드 지역의 강조 표시를 켜거나 끄는 설정 추가 (Viktor Govako)
