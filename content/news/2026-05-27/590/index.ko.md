5월의 두 번째 Organic Maps 업데이트에서 오류를 수정하고 기능을 개선했습니다. 자세한 내용은 아래에서 확인하세요. Organic Maps 팀은 프로젝트를 응원하고 [후원해 주시고](@/donate/index.ko.md), 주변에 알려 주시고, 좋은 후기를 남기고 [개발에 기여해 주신](@/contribute/index.ko.md) 모든 분께 감사드립니다. 개선된 [대중교통 기능](@/news/2026-05-08/580/index.ko.md)을 비롯해 더 많은 새 기능을 준비하고 있습니다!

<https://get.omaps.org>, [App Store][appstore], [Google Play][googleplay], [Huawei AppGallery][appgallery], [Obtainium][obtainium], [Accrescent][accrescent], [F-Droid][fdroid]에서 업데이트를 다운로드하세요.

### 모든 플랫폼

- 2026년 5월 27일 기준 OSM 지도 데이터 _(Viktor Govako)_
- 불 경기, 자전거, 모터스포츠 시설 아이콘 추가 _(Viktor Govako)_
- 기념문, 워터 슬라이드, 테마파크, 롤러코스터 추가 _(David Martinez)_
- 호주와 뉴질랜드의 도로 번호 표지 수정 _(Viktor Govako)_
- 길 안내 중 원근 보기에서 손가락 제스처로 지도를 조작하는 동작 개선 _(Viktor Govako)_
- 역 등 영역으로 표시되는 시설의 대중교통 노선 표시 수정(역이나 정류장을 누르면 노선 확인 가능) _(Viktor Govako)_
- 과속 단속 카메라의 제한 속도 표시 수정 _(Alexander Borsuk)_
- 지도가 여러 바퀴 이어져 보일 만큼 축소했을 때 180도 자오선 부근의 표시 문제 수정 _(Alexander Borsuk, Viktor Govako)_
- 도로명과 건물 주소를 더 정확하게 표시 _(Viktor Govako)_
- 불필요한 지도 애니메이션 수정 _(Mikhail Listratsenka)_
- 안정성 및 성능 개선 _(Alexander Borsuk, Viktor Govako)_

### 번역

- 프랑스어 번역 개선 _(Meenphie)_
- 이탈리아어 번역 개선 _(Andrea Pappacoda)_
- 스페인어 번역 개선 _(Jesús L. Pinzolas)_
- 우크라이나어 번역 개선 _(Nnifria)_
- 카탈루냐어 번역 개선, 여러 국가 및 지역 이름 번역 업데이트, `leisure=track` 검색 동의어 수정 _(Alexander Borsuk)_
- `disused:bridge`와 `disused:tunnel` 번역 수정 _(alnzrv)_

### iOS

- 신규: 북마크처럼 트랙에 일반 텍스트와 HTML 설명을 추가할 수 있습니다. 연필 아이콘을 눌러 설명을 추가하세요. _(Kiryl Kaveryn)_
- 텍스트 음성 변환(TTS)에서 해당 언어에 설치된 음성 중 품질이 가장 좋은 음성(향상됨 또는 프리미엄)을 선택합니다. 더 높은 품질의 음성을 다운로드하는 방법은 Organic Maps 설정에서 확인하세요. _(Kiryl Kaveryn)_
- 트랙의 새 이름이 제대로 반영되지 않던 문제 수정 _(Kiryl Kaveryn)_
- CarPlay에서 현재 위치를 지도 중앙에 표시하는 버튼 수정 _(Kiryl Kaveryn)_
- 등산이나 자전거 경로 위에 북마크를 추가할 때 발생하던 비정상 종료 수정 _(Alexander Borsuk)_

### Android

- 신규: 북마크처럼 트랙에 일반 텍스트와 HTML 설명을 추가할 수 있습니다. 연필 아이콘을 눌러 설명을 추가하세요. _(Mikhail Listratsenka)_
- 신규: 제공된 색상 외에도 원하는 트랙 색상을 자유롭게 선택 _(Mikhail Listratsenka)_
- 한국어, 중국어, 일본어 사용자의 기기 언어에 맞는 글꼴 사용 _(Alexander Borsuk)_
- 트랙 정보 화면과 ‘다른 앱에서 열기’ 버튼 문제 수정 _(Mikhail Listratsenka)_

### Linux 및 macOS

- `.desktop` 파일 설명에 중국어 번역 추가 _(DeepChirp)_
