2026년 8월 Organic Maps 업데이트를 <https://get.omaps.org>, [App Store][appstore], [Google Play][googleplay], [Huawei AppGallery][appgallery], [Obtainium][obtainium]에서 다운로드하세요([Accrescent][accrescent]와 [F-Droid][fdroid]에서도 곧 이용할 수 있습니다).

업데이트의 주요 기능
- 여러 북마크와 트랙을 한꺼번에 삭제하거나 이동하고 색상을 변경
- CarPlay 대시보드
- 지도에서 트랙을 개별적으로 숨기기
- 장소, 북마크, 현재 위치를 읽기 쉬운 링크로 공유
- 아르메니아어와 라오어 음성 안내
- 19개 언어의 위키백과 문서
이 밖의 개선 사항, 오류 수정, 지도 데이터 업데이트는 아래에서 확인하세요.

지난 [6월 업데이트](@/news/2026-06-29/610/index.ko.md)와 [7월 업데이트](@/news/2026-07-23/620/index.ko.md)의 변경 사항도 확인해 보세요.

## 전체 변경 내역

### 지도와 장소

- 2026년 8월 26일 기준 OpenStreetMap 데이터로 업데이트 _(Viktor Govako)_
- 아랍어, 벵골어, 중국어, 영어, 프랑스어, 독일어, 힌디어, 이탈리아어, 일본어, 한국어, 마라티어, 폴란드어, 포르투갈어, 러시아어, 스페인어, 타밀어, 텔루구어, 튀르키예어, 우르두어 위키백과 문서 업데이트 _(Alexander Borsuk)_
- 영업시간이 잘못 표시되던 여러 문제 수정 _(Alexander Borsuk)_
- 조류 관찰용 은신처 추가 _(Batmaclos, Viktor Govako)_
- 지도에 무대, 언덕, 자연 아치 지형을 추가하고 바위에 새 아이콘 적용 _(David Martinez)_
- 봉우리, 동굴, 고개 아이콘 크기 조정 _(David Martinez)_
- 보호 구역, 국립공원, 습지를 더 옅은 색으로 표시 _(Alexander Borsuk)_
- 앱이 멈추거나 때때로 터치와 제스처에 반응하지 않던 문제 수정 _(Alexander Borsuk)_

### 공유, 북마크 및 트랙

- 장소, 북마크, 현재 위치를 공유할 때 유용한 정보가 담긴 읽기 쉬운 링크 전송 _(Alexander Borsuk)_
- 북마크를 내보낼 때 본래 이름과 설명 유지 _(Alexander Borsuk)_
- 북마크 목록을 공유할 때 내부 파일 이름 대신 화면에 표시된 목록 이름 사용 _(Alexander Borsuk)_
- 트랙 기록을 시작한 직후 발생할 수 있던 고도 그래프 표시 문제 수정 _(Kiryl Kaveryn)_

### 경로 탐색과 길 안내

- 경로의 경유지나 표지를 누르면 계획된 다른 경로로 전환하지 않고 해당 지점의 정보를 표시 _(Viktor Govako)_
- 대중교통 경로 탐색 속도 향상 _(Viktor Govako)_
- 잘못된 방향 전환 안내 수정 _(Alexander Borsuk)_
- 경로를 다시 만든 뒤 출발지가 잘못 표시되던 문제 수정 _(Viktor Govako)_
- 경로 탐색 시 라테라이트 도로를 상태가 좋지 않은 비포장도로로 처리 _(Julien Etienne)_
- `access=unknown`이 붙은 도로를 사유 도로나 목적지에 접근할 때만 이용할 수 있는 도로와 같은 방식으로 처리 _(Julien Etienne)_
- 아르메니아어와 라오어 음성 안내 추가 _(Alexander Borsuk)_

### OpenStreetMap 편집기

- 영업시간 필드를 지워도 저장 또는 완료 버튼이 활성화된 상태로 유지 _(Alexander Borsuk)_
- 업로드가 일부 실패하면 모두 성공했다고 표시하지 않고 해당 업로드를 다시 시도 _(Alexander Borsuk)_

### 번역

- 일본어판을 포함해 [자주 묻는 질문](/ko/faq/) 업데이트 _(Alexander Borsuk)_
- ‘영업 종료’의 일본어 번역 수정 _(Viktor Govako)_
- ‘트랙’과 ‘비활성화’의 중국어 번역 개선 _(Chenxi Zhao)_

### iOS

- 신규: 북마크와 트랙을 여러 개 선택해 삭제, 이동, 색상 변경. 전체 선택 및 선택 해제도 가능 _(Kiryl Kaveryn)_
- 신규: CarPlay 대시보드 추가 _(Kiryl Kaveryn)_
- AirDrop으로 장소 공유 지원 _(Kiryl Kaveryn)_
- CarPlay의 여러 문제 수정 _(Kiryl Kaveryn, Alexander Borsuk)_
- 지도에서 북마크를 선택할 때 HTML 설명이 올바르게 표시되도록 수정 _(Kiryl Kaveryn)_
- 자동차 길 안내용 지도 스타일 적용 문제 수정 _(Kiryl Kaveryn, Alexander Borsuk)_
- 설정을 일반 설정, 지도, 내비게이션, 네트워크, 개인정보 보호로 재구성 _(Kiryl Kaveryn)_
- 나침반을 자동으로 보정하므로 수동 보정 설정 항목 제거 _(Kiryl Kaveryn)_
- 색상 팔레트 팝업에서 사용자 지정 색상 선택 도구 복원 _(Kiryl Kaveryn)_
- 도보나 자전거 경로의 미리 보기에서 고도 프로필을 따라 드래그하면 해당 지점을 지도에 표시 _(Kiryl Kaveryn)_
- 나침반 문제로 현재 위치 화살표가 잘못된 방향을 가리키거나 멈추던 현상 수정 _(Alexander Borsuk)_
- OpenStreetMap 업로드가 백그라운드에서 완료될 때 발생하던 비정상 종료 수정 _(Alexander Borsuk)_

### Android

- 신규: ‘북마크 및 트랙’ 목록에 다중 선택 모드 추가. 항목을 길게 누르거나 도구 모음에서 모드를 켠 뒤 선택한 북마크와 트랙을 한꺼번에 이동, 삭제하거나 색상을 변경할 수 있음 _(Mikhail Listratsenka)_
- 신규: 목록이나 트랙 정보 화면에서 눈 모양 아이콘을 누르면 트랙을 개별적으로 지도에서 숨길 수 있음 _(cyber-toad)_
- Android Auto 및 Android Automotive에서 유턴 차로 화살표 수정 _(Andrei Shkrob, Viktor Govako)_
- Android Auto 및 Android Automotive에서 주간·야간 모드 전환 문제 수정 _(Andrei Shkrob)_
- Android Auto 및 Android Automotive에서 검색어를 입력하는 동안 검색 목록을 열어 둠 _(Viktor Govako)_
- 목록을 정렬했을 때도 목록 설명을 표시 _(Mikhail Listratsenka)_
- 북마크 목록 설정 화면 디자인 개선 _(Mikhail Listratsenka)_
- 검색 카테고리를 누르면 검색 패널 접기 _(Mikhail Listratsenka)_
- 검색어를 지운 뒤 검색창으로 입력 포커스 이동 _(Mikhail Listratsenka)_
- 경로 고도 그래프를 패널 전체 너비로 표시 _(Mikhail Listratsenka)_
- 확대·축소 버튼이 화면 상단에 고정될 수 있던 문제 수정 _(Mikhail Listratsenka)_
- 모든 Android 버전에서 대화 상자의 모서리를 동일하게 둥글게 표시 _(Mikhail Listratsenka)_
- 트랙 내보내기 메뉴에서 발생하던 비정상 종료 수정 _(Mikhail Listratsenka)_
- 앱이 멈추던 문제 수정 _(Alexander Borsuk, Viktor Govako)_
- KML과 KMZ 파일을 중복으로 가져오거나 ‘파일을 열 수 없음’ 오류가 발생하던 문제 수정 _(Alexander Borsuk)_
- 브라질 포르투갈어, 멕시코 스페인어, 영국 영어의 검색 카테고리 수정 _(Alexander Borsuk)_
- 화면 표시 언어와 키보드 언어가 달라도 키보드 언어로 올바르게 검색 _(Alexander Borsuk)_
- OpenStreetMap 업로드가 오래 걸리거나 일부 실패해도 수정 사항이 사라지지 않도록 개선 _(Alexander Borsuk)_

### 데스크톱

- 장소 정보 화면에 공유 메뉴 추가(링크 복사, 텍스트 복사, 이메일…) _(Alexander Borsuk)_
- 다운로드 진행 표시를 코드로 그려 모든 화면에서 선명하게 보이도록 개선 _(Kuzey Bilgin)_
